# Contributing

Small improvements are welcome.

Please keep this repository:

- environment-light
- free of private paths, tokens, chat IDs, and company secrets
- focused on reusable operating rules, not one person's private infrastructure

## Skill changes

If you change `cloud-agent-operating-rules/SKILL.md`, keep the YAML frontmatter valid.

## Release principle

This skill should stay portable. Put environment-specific examples in separate notes, not in the core rules.
